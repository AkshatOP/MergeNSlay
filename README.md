# Merge & Slay: Tactical Grid

A 2048-inspired grid game with RPG combat mechanics.

[![Watch the video](https://raw.githubusercontent.com/AkshatOP/MergeNSlay/main/assets/thumbnail.png)](https://raw.githubusercontent.com/AkshatOP/MergeNSlay/main/assets/demo.mp4)



## Overview

Merge & Slay combines tile-merging puzzles with tactical combat. Slide tiles on a grid to merge weapons and battle monsters. The twist: items can only kill monsters if their level matches or exceeds the monster's level, creating a strategic puzzle where positioning and timing matter. Choose between 4×4 hardcore mode or 6×6 extended mode for different challenge levels.

## Gameplay Features

- **Grid-based merging** – Combine same-level items to create stronger weapons
- **Item vs monster combat** – Kill monsters with equal or higher-level items
- **Multiple grid sizes** – 4×4 (hardcore) or 6×6 (strategic) modes
- **Tactical blocking** – Under-leveled items can't pass stronger monsters
- **Cinematic victory sequence** – Multi-stage celebration with confetti and glow effects
- **GSAP-powered sliding** – Smooth, physics-based tile movement
- **Dynamic spawning** – New tiles appear after each move

## Controls

- **Arrow keys** or **WASD** – Move tiles
- **Swipe** – Touch gestures on mobile

## Tech Stack

- React
- Vite
- Tailwind CSS
- GSAP (tile sliding animations)
- Framer Motion (UI effects)
- react-confetti-explosion

## Getting Started

```bash
git clone https://github.com/AkshatOP/MergeNSlay.git
cd MergeNSlay
npm install
npm run dev
```

The game runs at `http://localhost:5173`.
